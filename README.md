# SUP Scheduler

Расписание аренды SUP-досок: таймлайн занятости по дням и часам, брони (в том числе на несколько досок сразу), проверка пересечений, финансы (заработано / забронировано вперёд / расходы).

Один статичный фронт + одна serverless-функция. Зависимостей нет.

## Структура

```
public/index.html      всё приложение (HTML + CSS + JS)
api/store/[key].js     key-value API (GET/PUT) поверх Upstash Redis, вход по паролю
```

## Как захостить на Vercel (бесплатно)

1. Зайди на [vercel.com](https://vercel.com) → **Sign Up** через GitHub.
2. **Add New… → Project** → импортируй репозиторий `sup-scheduler`.
3. Настройки не трогай (Framework Preset: **Other**, никаких build-команд) → **Deploy**.
4. Подключи бесплатную базу: в проекте вкладка **Storage → Browse Marketplace → Upstash → Redis** → выбери **Free** план → **Connect** к проекту. Переменные окружения (`KV_REST_API_URL`, `KV_REST_API_TOKEN`) добавятся сами.
5. Поставь пароль: **Settings → Environment Variables** → добавь `SUP_PASSWORD` = твой пароль (для всех окружений).
6. **Deployments → … → Redeploy**, чтобы функция подхватила переменные.
7. Открывай `https://<имя-проекта>.vercel.app` — при первом входе спросит пароль (тот самый `SUP_PASSWORD`), дальше запомнит.

## Важно

- **Без `SUP_PASSWORD` API открыт всем, у кого есть ссылка.** Поставь пароль сразу.
- Пароль хранится в localStorage браузера — вводится один раз на устройство.
- При первом открытии с пустой базой приложение один раз предложит заполнить брони за неделю 6–12 июля 2026 (сид в конце `index.html`, после использования можно удалить).
- Данные — три ключа в Redis: `sup_boards_v1`, `sup_bookings_v1`, `sup_expenses_v1` (JSON-строки). Запись целиком, последний писавший побеждает — для одного-двух пользователей нормально.
- Лимитов бесплатных планов (Vercel Hobby + Upstash Free: 500k команд/месяц) хватает с огромным запасом.
- Если открыть `public/index.html` просто файлом без сервера — приложение работает на localStorage этого браузера (удобно как офлайн-резерв).
